# ADR-011: localhost architecture

## Статус

Принято 27 июля 2026 года.

## Решение

CoA Raid Intelligence развивается как локальное браузерное приложение. Основной интерфейс открывается на `http://127.0.0.1:8000` и обслуживается FastAPI-приложением на том же компьютере.

## Каноническая архитектура

```text
Browser
  ↓ HTTP localhost
FastAPI application
  ↓
Planner / Catalog / Evidence Pipeline / Jobs
  ↓
DuckDB / Parquet / immutable raw JSON
```

## Правила

1. Вся доменная логика реализуется и тестируется в Python.
2. Браузер является основным пользовательским интерфейсом.
3. Сервер по умолчанию слушает только `127.0.0.1`.
4. DuckDB является каноническим локальным хранилищем планов, справочников и состояний задач.
5. Неизменяемые raw payloads хранятся отдельно от нормализованных данных и выводов.
6. Регрессионные сценарии оформляются как JSON/SQL/Python fixtures и автоматические тесты.
7. Импорт и экспорт являются периферийными функциями и не определяют внутреннюю архитектуру продукта.

## Последствия

Положительные:

- воспроизводимые unit/integration tests;
- нормальный Git diff и code review;
- единая модель для 10/25/40/FLEX;
- прямой доступ приложения к DuckDB;
- возможность выполнять тяжёлую аналитику в Python;
- локальное хранение пользовательских планов и наблюдений.

Ограничения:

- требуется локальный web-процесс;
- браузерный UI и API должны развиваться согласованно;
- канонические игровые выводы требуют реальных журналов боя, provenance и подтверждающих observations.
