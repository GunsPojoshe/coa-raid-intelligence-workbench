# ADR-011: localhost-приложение без Excel

## Статус

Принято 27 июля 2026 года.

## Решение

CoA Raid Intelligence развивается как локальное браузерное приложение. Основной интерфейс открывается на `http://127.0.0.1:8000` и обслуживается FastAPI-приложением на том же компьютере.

Excel, Power Query и VBA исключаются из рабочего контура продукта.

## Каноническая архитектура

```text
Browser
  ↓ HTTP localhost
FastAPI application
  ↓
Planner / Catalog / Analytics / Jobs
  ↓
DuckDB / Parquet / immutable raw JSON
```

## Правила

1. Вся доменная логика реализуется и тестируется в Python.
2. Браузер является единственным основным пользовательским интерфейсом.
3. Сервер по умолчанию слушает только `127.0.0.1`.
4. Приложение не требует Microsoft Excel.
5. Новые функции не реализуются формулами Excel, VBA или Power Query.
6. Историческая книга v9 хранится только как evidence миграции и источник проверочных примеров.
7. Регрессионные fixtures переводятся в JSON/SQL/Python-тесты.
8. DuckDB является каноническим локальным хранилищем планов, справочников и состояний задач.
9. Экспорт в CSV/XLSX может быть добавлен позднее только как выходной формат, но не как рабочий интерфейс или расчётное ядро.

## Отменённые решения

Следующие положения baseline v0.5 отменяются:

- Excel как основное рабочее место РЛа;
- CSV/Power Query как основной обмен интерфейса с Python;
- создание workbook v10;
- VBA/launcher для управления рабочим процессом;
- workbook regression как главный уровень приёмки.

## Новая стратегия миграции

1. Извлечь из v9 классы, специализации, роли, эффекты и правила в versioned data fixtures.
2. Зафиксировать известные результаты v9 как JSON evidence, не как исполняемую книгу.
3. Реализовать эквивалентные проверки в Python.
4. Создать localhost-конструктор на 25 как первый regression-сценарий.
5. Добавить FLEX, 10 и 40 через единую модель активных слотов.
6. Подключить сохранение планов в DuckDB.
7. Перенести coverage, рекомендации и сравнение специализаций в API и web UI.

## Последствия

Положительные:

- нормальный Git diff и code review;
- воспроизводимые unit/integration tests;
- отсутствие зависимости от версии Excel и cached formula values;
- динамический интерфейс для 10/25/40/FLEX;
- прямой доступ приложения к DuckDB;
- более быстрый вайбкодинг и рефакторинг.

Отрицательные:

- требуется локальный web-процесс;
- браузерный UI нужно создать заново;
- правила из v9 необходимо явно мигрировать;
- исторический workbook больше нельзя считать исполняемым эталоном.
