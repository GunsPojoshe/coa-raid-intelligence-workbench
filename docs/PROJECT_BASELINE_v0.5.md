# CoA Raid Intelligence Workbench

## Промежуточная эволюционная версия

**Версия:** 0.5  
**Статус:** канонический baseline промежуточного продукта  
**Платформа:** Windows 11, локальный однопользовательский режим  
**Форматы состава:** FLEX / 10 / 25 / 40  
**Канонический regression baseline:** 25 игроков и текущая логика Excel v9

> Excel остаётся основным рабочим интерфейсом РЛа. Большие данные, синхронизация, нормализация и тяжёлые расчёты выносятся в Python и локальное хранилище. VBA используется только как тонкий слой запуска, импорта, экспорта и обновления экрана.

Полная каноническая документация находится в DOCX-файле той же версии.

## Ключевая архитектура

`API/JSON → Raw archive → Python normalizer → DuckDB/Parquet → CSV/JSON exchange → Excel`

## Ключевые решения

- Одна книга поддерживает FLEX, 10, 25 и 40 через `RaidFormat`, `TargetSize` и `ActiveSlot`.
- Лист состава содержит 40 физических строк; неактивные строки не участвуют в расчётах.
- 25 игроков остаются regression baseline, но не единственным поддерживаемым размером.
- Сырые timeline-события не загружаются в Excel.
- Основной обмен с книгой — versioned CSV/JSON и Power Query.
- VBA не содержит бизнес-логику.
- Первая версия сохраняет пошаговый советник; CP-SAT является последующим улучшением.
- Наблюдение, кандидатная связь, подтверждение и manual override хранятся раздельно.

## Definition of Done

РЛ обновляет данные, выбирает формат и размер, отмечает доступность, получает объяснимые рекомендации, собирает состав, сохраняет snapshot и экспортирует план без ручной переклейки логовых листов и без загрузки миллионов строк в Excel.
